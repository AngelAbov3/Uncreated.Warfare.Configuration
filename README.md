This repository stores some of the configuration files for [Uncreated.Warfare](https://github.com/UncreatedStaff/UncreatedWarfare). Many of the files are incomplete to remove API keys, plugins, and other sensitive or unnecessary data.

See the documentation for [Uncreated.Warfare](https://github.com/UncreatedStaff/UncreatedWarfare) for more information on this repository.

After cloning, run this command to not push your system config.
```powershell
git update-index --assume-unchanged "System Config.yml"
```
